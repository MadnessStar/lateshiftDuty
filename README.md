# 늦조 근무 자동 편성 시스템

한컴말랑말랑행복케어주야간보호센터의 늦조(11:00~20:00) 근무 편성을 자동화하는 웹 앱입니다.  
엑셀 근무표 파일을 업로드하면 조건에 맞는 늦조 가능 인원을 날짜별로 자동 계산합니다.

---

## 주요 기능

- 근무표 엑셀(.xlsx/.xls) 업로드 → 요양보호사 데이터 자동 파싱
- 업로드한 파일의 연도·월을 자동 감지 → 해당 월 한국 공휴일 자동 표시
- 토·일·공휴일 자동 제외
- 남자 요양보호사 고정 제외 (오태봉·현택정·김연욱)
- 휴무·연차·교육·단기보호 제외
- 개인별 조건 적용 (이정옥·김명숙·위은실·홍채연·탁정심)
- 결과 텍스트 복사 / 인쇄 지원

## GitHub Pages 배포 방법 (처음 하는 경우)

### 1단계 — GitHub 계정 만들기
1. [https://github.com](https://github.com) 에 접속해 **Sign up** 클릭
2. 이메일·비밀번호·사용자명 입력 후 계정 생성

### 2단계 — 새 저장소(Repository) 만들기
1. 로그인 후 우측 상단 **+** → **New repository** 클릭
2. Repository name 입력 (예: `neutjo-scheduler`)
3. **Public** 선택 (GitHub Pages 무료 사용을 위해 필수)
4. **Create repository** 클릭

### 3단계 — 파일 업로드
1. 생성된 저장소 페이지에서 **uploading an existing file** 링크 클릭  
   (또는 **Add file → Upload files**)
2. 이 프로젝트 폴더 안의 파일들을 모두 드래그 앤 드롭:
   ```
   index.html
   css/
   js/
   README.md
   ```
3. 화면 하단 **Commit changes** 클릭

### 4단계 — GitHub Pages 활성화
1. 저장소 상단 메뉴 **Settings** 클릭
2. 왼쪽 사이드바 **Pages** 클릭
3. **Source** 섹션에서:
   - Branch: `main`
   - 폴더: `/ (root)`
4. **Save** 클릭
5. 1~3분 후 페이지 상단에 URL이 표시됩니다:  
   `https://[내 사용자명].github.io/neutjo-scheduler`

> ⚠️ 파일 수정 후 다시 업로드하면 자동으로 사이트가 갱신됩니다.

## 공휴일 데이터 업데이트

음력 기반 공휴일(설날·추석·부처님오신날)은 `js/holidays.js` 파일의  
`LUNAR_HOLIDAYS` 객체에 연도별로 미리 입력되어 있습니다.

현재 내장 연도: **2024 · 2025 · 2026**

2027년 이후 데이터를 추가하려면 `js/holidays.js` 를 열어  
아래 형식으로 추가하세요:

```js
LUNAR_HOLIDAYS[2027] = [
  { date: '2027-02-07', name: '설날 전날' },
  { date: '2027-02-08', name: '설날' },
  { date: '2027-02-09', name: '설날 다음날' },
  // ... 추석, 부처님오신날 등
];
```

또는 웹사이트에서 파일 업로드 후 **공휴일 수동 추가** 기능으로  
해당 월만 직접 입력할 수도 있습니다.

## 프로젝트 구조

```
늦조 근무 자동화/
├── index.html          ← 메인 페이지 (UI)
├── css/
│   └── style.css       ← 스타일
├── js/
│   ├── constants.js    ← 상수 (남자 요양보호사 목록, 개인 조건 등)
│   ├── holidays.js     ← 한국 공휴일 데이터 및 계산 함수
│   ├── excelParser.js  ← 엑셀 파일 파싱 (SheetJS 사용)
│   ├── scheduler.js    ← 늦조 편성 핵심 알고리즘
│   └── main.js         ← UI 이벤트 처리 및 앱 흐름
└── README.md           ← 이 파일
```

## 엑셀 파일 파싱이 잘 안 될 때

파서는 다음 조건으로 자동 감지합니다:
- **날짜 헤더**: 1, 2, 3 … 이 연속으로 28개 이상 있는 행
- **구분 열**: 정확히 `구분` 이라는 텍스트가 있는 셀
- **이름 열**: 구분 열 바로 오른쪽
- **연도·월**: `2026년 5월` 형태 텍스트가 포함된 셀

파싱 경고가 뜨면 브라우저 콘솔(F12 → Console)에서 상세 메시지를 확인할 수 있습니다.
